Where to find it

  • Bot: AI Agents, then Conversation AI, then Agents List
  • Widget: Sites, then Chat Widget
  • Stamping: Workflows, folder "Webchat Center Stamping"
  • Alert: Workflows, "Chat Bot Hand-off Email Alert"

When to edit

  • Bot gave a wrong answer: fix that location's PawConnect page. Don't touch the bot.
  • Location inbox changed: update the location's user email in Settings, then Users. Hand-off alerts follow it.
  • Change how all bots behave: all 83 share the same rules, so change every bot the same way (use the bulk-edit skill).
  • Keep switched on: the hand-off alert workflow and the stamping workflows.
Marking a quiet chat as Read without replying wakes the bot up again. Staff should reply or leave it.

Automatic texts

Welcome texts go out from the location's own number, only to customers who opted in.

STOP

GHL stops texting that customer automatically.

MoeGo

Booking confirmations, reminders and changes come from MoeGo's own number.

Where to find it

  • Numbers: Settings, then Phone System (one per location, named "BFPH - …")
  • Bot texting: each bot's Deploy tab. SMS is off on all 83.

When to edit

  • New location: buy a local number and link it to the location's user.
  • Bots answering texts: only if Best Friends decides it. Switch SMS on per bot in Deploy.

Where to find it

  • Sender: Workflows, "Manager Reports - Send Email" (keep published)
  • Script and manager list: the Manager Reports package

When to edit

  • Manager inbox changes: edit that location in the locations file.
  • Different send time: change the schedule in the script.
  • Contacts missing from a report: they have no loc: tag.

Updating location info

The bots read each location's facts live, so updating PawConnect is all it takes. Nothing changes in GHL.

Hours, prices or services change
Update the location's PawConnect page

Suggest an edit, highlight the text, Request edit

The fact card updates

Built from the same page

next chat
Bot's "Get center facts" reads the new card

Where to find it

  • PawConnect knowledge base, one page per location (center code, e.g. BF3)

When to edit

  • Same day a price or hour changes, so the bot never quotes old info.
  • Hours, phone, address: these come from the master sheet, so send them to an admin.
  • Booking link changes: also update the location's welcome emails in GHL.
